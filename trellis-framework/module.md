# Граница Trellis Framework

## Назначение

Framework определяет декларативные контракты Trellis: формат YAML-документов, состав доменов, определения агентов и навыков, рендер, проверку и принятие изменений.

## Внутренние границы

- [Contracts](contracts/module.md) — общие соглашения, JSON Schema конфигурации и документов процесса.
- [Domains](domains/module.md) — предметные схемы и связанные с ними агенты и представления.
- [Examples](examples/module.md) — конкретные учебные документы и сценарии применения контрактов.
- [Конфигурация доменов](domains.yaml) — точка сборки доменной модели.

## Зависимости и ограничения

Framework не исполняет агентов, не хранит рабочую базу знаний и не применяет изменения. Проверки выполняет Knowledge; запуск агентов — Runtime; интерфейс — клиент.

Форма данных описывается JSON Schema в YAML. Семантика полей и смысловые критерии находятся рядом со схемой. Описания границ объясняют ответственность каталогов. Примеры не вводят новых общих типов.
