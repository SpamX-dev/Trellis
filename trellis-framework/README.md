# Trellis Framework

Исходные контракты, из которых компоненты Trellis получают схемы проверки, контекст агента, правила размещения документов и человекочитаемые представления.

## Структура

- [contracts](contracts/module.md): документ, конфигурация домена и жизненный цикл изменения.
- [domains](domains/module.md): продукт, комплаенс и проверка комплаенса.
- [examples](examples/module.md): согласованный набор YAML-документов и предложение правки.
- [domains.yaml](domains.yaml): ссылки на схему, агента и рендер каждого домена.

## Домен как конфигурация

Каждый домен содержит три связанных артефакта:

| Артефакт | Содержание |
| --- | --- |
| schema | JSON Schema типов документов; описания, цели ссылок и смысловые критерии. |
| agent | Ответственность, инструкции и навыки со ссылками на схемы. |
| render | Подписи и порядок полей для чтения и сравнения документов. |

Схемы написаны в диалекте JSON Schema 2020-12. Поддержка в редакторе проверяется отдельно; проверка репозитория использует [Ajv 2020](https://ajv.js.org/json-schema.html#draft-2020-12-breaking). Собственные аннотации регистрируются явно при сохранении строгой проверки схем.

Сборка агента сочетает авторские инструкции с выбранной схемой, её критериями и примерами. Она не выводит источники знаний или процедуру интервью из типов полей.
