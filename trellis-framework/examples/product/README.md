# Учебный продукт

Документы примера хранятся как YAML в [documents](documents/): по одному документу каждого из шести типов — Product, US, FR, NFR, BO и BP. US, FR, NFR, BO и BP ссылаются на один Product; FR также ссылается на US, BO и NFR; шаг BP ссылается на FR. Сценарий вымышленный и служит примером формы документов.

Размещение повторяет [план](../../plan.md): `documents/product/<type>/<id>.yaml`, где `<type>` — тип документа, а имя файла совпадает с `id`.

Типы документов объявлены в [model.ts](../../src/product/model.ts). Их форму компилятор проверяет в [проверках типов](../../test/model-types.ts); `parseProductDocument` дополнительно проверяет непустые строки, уникальность имён групп и форму ссылочных ID. `checkProductSnapshot` проверяет весь набор файлов области: строгий YAML, размещение путей, единственный Product и существование целей ссылок. Сценарий чтения снимка из временного Git-репозитория добавляется следующим шагом [плана](../../plan.md).
