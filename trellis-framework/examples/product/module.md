# Граница примера product

Каталог описывает один продукт шестью типами документов — Product, US, FR, NFR, BO и BP — в виде YAML и сквозную проверку этих документов из точного commit временного локального Git-репозитория. Сценарий пользуется публичными экспортами Framework и не запускает настоящего агента.
