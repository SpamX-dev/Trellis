# Примеры знаний и процессов

## Назначение и ответственность

Каталог содержит конкретные экземпляры знаний, связи и сквозные сценарии использования контрактов Trellis.

## Границы

Примеры используют типы [Semantic Model](../semantic-model/module.md) и порядок работы из [Workflows](../workflows/module.md). Они не определяют альтернативную метамодель, общие правила API, навыки для установки или реальные результаты проверок. Условные источники, решения человека и Evidence явно обозначаются как данные сценария.

## Зависимости

Изменение общей семантики выполняется в Framework; пример обновляется вслед за ней. Данные примера не являются каноническим Knowledge State пользовательского проекта и не предоставляют разрешений на действия Runtime.
