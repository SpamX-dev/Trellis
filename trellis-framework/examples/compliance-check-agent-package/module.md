# Граница примера проверки комплаенса

## Назначение

Каталог описывает одну задачу: оценить один продукт по выбранным ограничениям и опубликовать предложение оценок в Git. [Контракт пакета](../../contracts/agent-package.md) связывает инструкцию, навык, схемы входа и выхода и машинные гейты.

## Границы

Вход задаёт область чтения, идентификатор продукта, выбранные ограничения и разрешённые пути записи. Проект и базовые ревизии задаёт задача Tasks. Выход содержит ветку предложения и точный commit. Knowledge выводит ChangeSet из разницы с базовой ревизией, проверяет изменённые пути и валидирует итоговый снимок. Принятие предложения остаётся решением человека.
