# Граница product

Каталог определяет типы Product, US, FR и NFR, правила их проверки, агента сбора требований и его навык. Типы с комментариями служат контрактом, передаваемым исполнителю как текст; правила проверки покрывают и то, что типы не выражают, — форму идентификатора, непустые списки и уникальность значений. Ссылки между документами известны этому каталогу; общий слой Framework не содержит реестра доменов.

Документы хранятся в Git как YAML. Продуктовый код принимает данные и содержимое точной ревизии от вызывающего компонента; он не выдаёт доступ к проекту, не запускает агента и не принимает изменения за человека.
