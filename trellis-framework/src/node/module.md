# Граница node

Каталог выполняет файловые операции, необходимые библиотеке Framework: чтение локальных ресурсов, строгий разбор YAML и сборку файлового комплекта product-агента. Он не управляет проектными правами, Git-репозиториями и исполнением внешнего агента.

Корневая точка входа Framework остаётся свободной от файловых операций. Зависимый от Node.js код доступен через отдельный импорт `@trellis/framework/node`.
