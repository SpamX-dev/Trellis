# Граница схем продуктового домена

## Назначение

[Состав домена](schema.yaml) объединяет восемь отдельных JSON Schema типов документов. Каждый файл типа определяет форму документа, смысл полей, ссылки и критерии проверки.

## Границы

Файлы типов являются единственным источником правил для машинной проверки и контекста агента. Общие определения идентификатора и источника берутся из [контракта](../../../contracts/common.schema.yaml); смысловые `x-trellis-checks` не заменяют детерминированную проверку структуры и ссылок.
