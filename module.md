# Trellis

## Ответственность

Trellis — продукт для VS Code / Cursor, объединяющий расширение редактора и управляемый fork Grafel. Корневой репозиторий определяет состав продукта, совместимую ревизию движка и правила сборки поставки.

## Границы

- `grafel/` — отдельный Git-репозиторий, подключённый как submodule. Отвечает за анализ исходников, граф, поиск, MCP и dashboard. Его внутренняя структура сохраняет совместимость с upstream `cajasmota/grafel`.
- `plugin/` — расширение редактора, принадлежащее истории Trellis. Отвечает за управление движком, индексацию workspace, отображение состояния, подключение MCP и открытие dashboard.
- `scripts/` — автоматизация сборки, проверки и упаковки продукта. Не содержит логику анализа кода или поведения интерфейса.
- `docs/` — пользовательские требования и дорожная карта продукта. Не заменяет архитектурные контракты компонентов и доказательства приёмки.

## Зависимости и ограничения

Расширение взаимодействует с Grafel через явные интерфейсы процесса, команд и API. Внутренние структуры хранения графа не являются контрактом расширения. Компоненты Grafel не зависят от API редактора.

Корневой коммит фиксирует точный коммит submodule. Сборка использует эту ревизию, а не плавающую вершину удалённой ветки. Изменения движка сначала публикуются в его fork, затем ссылка обновляется в Trellis.

Целевая поставка — один VSIX для Windows x64 с собранным движком и dashboard. Разделение исходников на репозитории не определяет количество поставляемых артефактов.
