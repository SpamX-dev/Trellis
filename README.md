# Trellis

Система управления семантически связанными инженерными знаниями и трассировки влияния изменений от требований и архитектурных решений до задач, репозиториев, коммитов и проверок.

## Ограничения

Не анализирует код, не строит LSP дерево

## Что реально содержит

База знаний содержит семантический граф инженерного знания. Документы являются типизированными представлениями частей этого графа.
Т.о. вся БЗ связана в единый граф и для добавления документов в БЗ нужно описать семантику связи с другими документами.

## Как это работает

### Роли

- Оператор
- Агент
- Навык
- База зананий
- Документ

### Последовательность

- Оператор хочет изменить документ (требования к продукту, требовани к архитектуре или иной документ)
- Агент смотрит на семантику документа - проводит опрос
- Агент берет необходимый навык и формирует изменения в граф знаний
- БЗ принимает изменения и строит черноик измнений
- Рендерит документ
- Человек смотрит на изменения в графе и документах
- Применяет изменения

## Использование

### Проблематика

Обычно изменение не затрагивает один репозиторий и принять решение довольно сложно.

### Решение

Когда требование сфоромировано, оно разложится в граф и установит влияние, можно провести трассировку и выяснить затрагиваемые цепочки.
Тогда будет сразу видно что нужно менять и где.


```
Operator intent
      │
      ▼
Agent + Skill
      │
      ▼
Semantic ChangeSet
      │
      ▼
Knowledge Graph draft
      │
      ├────> Document rendering
      │
      ├────> Graph diff
      │
      └────> Impact analysis
               │
               ▼
          Human approval
               │
               ▼
       New Knowledge State
```

Практически весь основной workflow вращается вокруг:

```
Current Knowledge State
          │
          │ intent
          ▼
      ChangeSet
          │
          ├── add node
          ├── modify node
          ├── remove node
          ├── add relation
          ├── remove relation
          └── justification / provenance
          │
          ▼
      Draft State
```
