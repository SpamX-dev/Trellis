# Trellis Knowledge

Работа с YAML-документами и их изменениями.

## Хранение

Принятое состояние — согласованный снимок каталога документов. Файлы раскладываются по домену, типу и идентификатору согласно [правилам документов](../trellis-framework/contracts/documents.md). Их можно читать и искать обычными файловыми инструментами.

Граф строится по запросу из явно заданных ссылок. Он содержит область построения и ревизию источников. Отдельное хранилище графа и постоянный индекс для поиска по id не обязательны.

## Запись

Агент готовит рабочее предложение с одним или несколькими документами. Knowledge проверяет итоговый снимок, показывает различия, принимает решение человека и повторно проверяет базовую ревизию перед применением.

Создание и изменение документа, удаление, повторы и конфликты описаны в [контракте изменений](../trellis-framework/contracts/changes.md). Выбор физического способа атомарной публикации снимка относится к реализации Knowledge.

## Проверка репозитория

[Проверка](validation/check.mjs) запускается из корня:

```sh
npm run check
npm test
```

Она проверяет конфигурацию Framework, схемы, учебные документы, ссылки, правила комплаенс-оценки и итог учебного ChangeSet в памяти. Код не записывает принятые документы и не моделирует надёжность файловых транзакций.

## Граница реализации

Хранилище ревизий, публикация принятых снимков, MCP-сервер и событийная доставка требуют реализации. Исполняемый артефакт этого компонента — локальная проверка контрактов и примеров.
