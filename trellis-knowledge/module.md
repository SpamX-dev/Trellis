# Граница Trellis Knowledge

## Назначение

Knowledge управляет принятыми YAML-документами, предложениями изменений и историей по контрактам [Framework](../trellis-framework/module.md). Документы являются каноническим представлением знаний.

## Ответственность

- Чтение файлов и поиск документов по идентификаторам.
- Проверка YAML, схем, уникальности идентификаторов и типов целей ссылок.
- Проверка итогового набора документов при изменении нескольких файлов.
- Сохранение предложения, решения человека и согласованное применение к базовой ревизии.
- Построение графа из выбранного снимка документов по явным ссылкам схем.
- Выдача MCP-операций для работы с контрактами и предложениями.

[Validation](validation/module.md) владеет детерминированной проверкой контрактов и примеров.

## Границы

Граф и индексы являются производными. Постоянная графовая БД и индекс идентификаторов не требуются для файлового поиска. Путь документа не определяет его идентичность.

Knowledge не выполняет содержательное рассуждение, не запускает LLM и не публикует пакеты. Он проверяет технические условия принятия; содержание оценивают агент и человек. Прямое редактирование рабочей копии не делает её принятым состоянием.
