# Граница проверки Knowledge

Validation отвечает за детерминированную проверку переданных YAML-документов и их связей. Для первого продуктового сценария правила определяет [Framework](../../trellis-framework/module.md); Knowledge передаёт библиотеке содержимое точного Git-снимка и получает структурированные результаты проверки.

Validation проверяет синтаксис, размещение, типы документов, идентификаторы и ссылки в пределах переданной области. Он не получает проектные права, не загружает Git-ревизии и не принимает изменения. [Repositories](../repositories/module.md) предоставляет снимок, Projects проверяет доступ, а решение о принятии координирует Knowledge.

Смысловую правильность требований и корректность реализации программного продукта структурная проверка не доказывает. Временные связи между документами не требуют постоянного графового хранилища.
