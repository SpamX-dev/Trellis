# Граница сервера Knowledge

Nest-приложение собирает HTTP API, проверку личности и права, а также операции Projects и Repositories. Оно не переносит владение метаданными в Repositories и не принимает знания без отдельного оркестратора принятия. Транспортные контроллеры вызывают доменные сервисы, а не исполняют Git или SQL напрямую. Общий контракт первого этапа описан в [контракте API](../contracts/projects-repositories.md).
