# Trellis Web

Браузерный клиент первого этапа Projects и Repositories. [Граница](module.md) отделяет отображение от решений о проектных правах и состояния задач.

Стек: React, Vite, Ant Design и OIDC Authorization Code + PKCE. После входа UI показывает назначенные проекты, настройки владельца и участника, агентские учётные записи и доступные коммиты `main`. Токен агента виден только при выпуске; существующие токены можно отозвать.

В целевом цикле этот же клиент показывает задачи [Tasks](../trellis-tasks/module.md), вопросы агента и итоговые результаты [Knowledge](../trellis-knowledge/module.md), принимает ответы человека и открывает предложения для просмотра и решения. Интерфейс задач пока не реализован.

Из корня репозитория `npm run dev:web` запускает Vite на `http://localhost:5173/` и проксирует `/api` к локальному серверу Knowledge на порту 3000. Контейнерный запуск описан в [Knowledge](../trellis-knowledge/README.md).
