# Изменения

## 0.2.1

- Список папок и выбор проекта сосредоточены в боковой панели; вкладка остаётся пустой до подключения Grafel.
- Проверка доступности и журнал вынесены в заголовок панели.
- Команда открытия вкладки доступна только в палитре; удалены ресурсы и транспорт команд прежней страницы.

## 0.2.0

- Общий выбор проекта по URI для боковой панели и стартовой вкладки; сброс при удалении корня из workspace.
- Полные пути и состояния папок, диагностика локальных и неподдерживаемых URI, повторная проверка доступа и ограниченный журнал.
- Подготовка контекста анализа с проверкой доверия, доступности и смены выбора во время ожидания.
- Проверки штатного добавления/отмены, одноимённых папок, перезапуска и UI в изолированных VS Code / Cursor.

## 0.1.0

- Боковая панель Trellis со списком папок workspace.
- Отдельная вкладка Trellis, обновляющаяся при изменении состава workspace.
- Команды открытия стартовой вкладки, добавления папки и перехода к папке в проводнике редактора.
- Самостоятельный VSIX без Grafel, загрузки зависимостей и запуска внешних процессов.
