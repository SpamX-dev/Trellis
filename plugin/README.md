# Trellis

Рабочая область Trellis внутри VS Code / Cursor.

## Использование

1. Установите `trellis-0.1.0.vsix` через **Extensions: Install from VSIX…**.
2. Откройте значок **Trellis** в боковой панели.
3. Выберите **Открыть Trellis**, чтобы открыть стартовую вкладку. Команда также доступна в палитре команд.

Боковая панель и вкладка показывают реальные папки workspace. Список обновляется при добавлении или удалении папок. Выбор папки в боковой панели открывает её в проводнике редактора. При пустом workspace доступна команда добавления папки.

Повторное открытие Trellis активирует существующую вкладку. Расширение не открывает её автоматически при запуске редактора.

Версия 0.1.0 содержит оболочку расширения: Grafel, индексация, граф и MCP не входят в эту поставку. Расширение не скачивает компоненты, не запускает внешние процессы и не отправляет данные проекта.

## Сборка

Нужны Node.js 22+ и npm. Из директории `plugin/`:

```powershell
npm ci
npm run check
npm run package
```

Результат: `plugin/trellis-0.1.0.vsix`. Для этой сборки не требуется инициализация submodule Grafel. Пакет содержит скомпилированное расширение и локальные ресурсы; исходники тестов и зависимости разработки исключены.

## Проверка в редакторе

```powershell
$env:TRELLIS_TEST_EXECUTABLE = 'C:\path\to\Code.exe'
npm test
```

Для Cursor укажите путь к `Cursor.exe`. Без переменной тестовый инструмент скачивает стабильный VS Code. Тесты используют отдельные временные профили и каталоги расширений, проверяют активацию, команды, жизненный цикл вкладки и изменение workspace. Пути к тестовому профилю и журналам выводятся в консоль.

Для проверки распакованного VSIX можно дополнительно задать `TRELLIS_TEST_EXTENSION_PATH` — путь к директории `extension/` внутри распакованного пакета.

В корневом репозитории доступна конфигурация **Run Trellis** для запуска расширения через F5. Она собирает плагин и запускает Extension Development Host в текущем редакторе (`Code.exe` или `Cursor.exe`). Установленные пользовательские расширения отключены в окне разработки; разрабатываемый Trellis загружается из `plugin/`. Исходное окно проекта остаётся открытым: одно дополнительное окно Extension Development Host при F5 — штатное поведение.

После открытия выберите значок Trellis в боковой панели и команду **Открыть Trellis**. Изменения исходников требуют повторного запуска; для непрерывной компиляции используйте `npm run watch`.
