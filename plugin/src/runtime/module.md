# Управление движком

## Ответственность и границы

Блок отвечает за жизненный цикл процесса движка: запуск, остановку, наблюдение за состоянием и владение ресурсами. Он учитывает изоляцию данных Trellis и работу нескольких окон редактора.

Команды и API движка инкапсулируются в соседнем блоке `grafel`. Представление ошибок и состояния пользователю относится к `ide`. Сборка и доставка исполняемых файлов относятся к автоматизации поставки.
