# Адаптер Grafel

## Ответственность и границы

Блок инкапсулирует взаимодействие с согласованными командами и API Grafel, преобразует ответы движка в данные для расширения и сообщает об ошибках совместимости.

Он не владеет интерфейсом редактора и не запускает процесс движка: эти обязанности относятся к `ide` и `runtime`. Внутренний формат индекса Grafel не используется как интерфейс интеграции.
