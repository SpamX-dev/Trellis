# Интеграция с редактором

## Ответственность и границы

Слой `ide` содержит команды, дерево workspace и вкладки Trellis. Источником сведений о workspace является API редактора; названия и пути папок обрабатываются как недоверенный текст.

Представления владеют своими подписками и освобождают их при закрытии или деактивации. Открытие вкладки повторно активирует существующий экземпляр в том же окне редактора.

Этот слой не запускает движок, не читает формат индекса и не реализует анализ кода. HTML-представление отделено от жизненного цикла Webview; стили находятся в `media/` и используют тему редактора.
