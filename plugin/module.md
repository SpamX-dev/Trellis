# Расширение Trellis

## Ответственность

Расширение интегрирует Grafel в VS Code / Cursor: управляет запуском и остановкой движка, инициирует индексацию workspace, показывает состояние и ошибки, обеспечивает подключение MCP и открытие dashboard.

## Внутренние границы

Управление процессом, взаимодействие с Grafel и представление в редакторе разделяются по ответственности. Код представления использует адаптер Grafel; он не разбирает файлы индекса и не обращается к внутренним структурам движка.

Открытие dashboard отделяется от управления движком. Браузер и вкладка IDE являются способами представления одного dashboard и не требуют переноса анализа кода в расширение.

- `src/extension.ts` — точка композиции команд и представлений.
- `src/ide/` — интеграция с редактором: дерево workspace, вкладки и представление данных.
- `src/runtime/` — управление процессом движка.
- `src/grafel/` — адаптер команд и API Grafel.
- `media/` — локальные ресурсы интерфейса.
- `test/` — проверки расширения в изолированном Extension Host.

Оболочка редактора должна собираться и запускаться независимо от движка. Подключение runtime и адаптера выполняется в точке композиции и не является условием открытия представлений workspace.

## Зависимости и ограничения

Расширение зависит от API редактора и согласованных интерфейсов Grafel. Совместимая ревизия движка задаётся корневым репозиторием. Данные и процессы Trellis должны быть изолированы от отдельно установленного Grafel; работа нескольких окон редактора должна учитываться при управлении жизненным циклом.

Директория принадлежит корневому Git-репозиторию Trellis и не является отдельным submodule. Сборочные артефакты и зависимости не коммитятся.
