# Проверки расширения

## Ответственность и границы

Блок проверяет активацию, команды заголовка боковой панели, дерево workspace и жизненный цикл пустой вкладки внутри Extension Host. Для рабочих данных используются отдельные временные папки и сохранённый тестовый workspace.

Запускающий процесс создаёт изолированные профили редактора и каталоги расширений. Исполняемый файл редактора и путь к проверяемому расширению могут передаваться извне, что позволяет проверить VS Code, Cursor и содержимое распакованного VSIX одним набором сценариев.

Тестовые зависимости и исходники не входят в поставляемый пакет. Эти проверки не запускают Grafel и не подтверждают функциональность анализа кода.

`run.cjs` управляет временными данными и отдельными запусками редактора, `suite/index.ts` проверяет команды и API внутри Extension Host, `ui.cjs` выполняет действия и проверяет отрисованный интерфейс через Playwright/CDP тестового окна. Для сценариев используется штатный упрощённый диалог папок редактора. Рабочий профиль и его настройки не затрагиваются.

При проверке распакованного VSIX компоненты загружаются из `dist` этого пакета. JSON-результаты, журналы и скриншоты сохраняются во временном каталоге; статус прохождения выводится только после проверок хоста и UI.
