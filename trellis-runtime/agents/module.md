# Граница agents

Каталог содержит реализации агентов, доступных для запуска в этом экземпляре Runtime, в виде Markdown-текстов — без TS-описаний агентов. Библиотека [Framework](../../trellis-framework/module.md) остаётся набором типов и проверок и не содержит определений агентов.

Декларации типов моделей копируются в текст агента вручную; источник истины — библиотека. При её изменении копии обновляют вручную, а совместимость проверяют исполняемые проверки библиотеки. Пакет для внешнего исполнителя собирается из этих текстов и деклараций отдельным шагом.

Локальные Markdown-ссылки проверяет корневая команда `npm run check`.
