# Trellis Runtime

Среда исполнения задач агентов с доменными YAML-документами. Жизненным циклом задач управляет [Tasks](../trellis-tasks/module.md).

## Вход запуска

- Назначенная Tasks работа для агента, имя которого включено в конфигурацию Runtime.
- Закреплённый пакет агента из [Registry](../trellis-registry/module.md) и выбранный домен из [конфигурации](../trellis-framework/domains.yaml).
- Точная ревизия Framework и базовый снимок документов.
- Разрешённые Knowledge файловые снимки и инструменты с дополнительными ограничениями среды запуска.

Runtime собирает инструкции агента, навык, схему целевого документа, её смысловые критерии и нужные примеры из закреплённого пакета и снимка Framework. Внешний агент запускается через CLI/SDK-адаптер. Чтение соседних документов осуществляется файлами; MCP используется там, где нужна операция сервиса.

[Projects](../trellis-knowledge/projects/module.md) проверяет проектный доступ, а [Repositories](../trellis-knowledge/repositories/module.md) предоставляет локальные снимки точных ревизий и изолированные рабочие копии. Runtime не расширяет эти разрешения и не управляет учётными записями или жизненным циклом проектов.

## Результат

Результат автора — предложение документов и открытые вопросы. Результат AI-проверки — находки по объявленным критериям, основания и неопределённость. Проверяющий навык сам по себе не получает права применения.

Ход исполнения и вопросы человеку передаются в Tasks, итоговые артефакты и предложения — в Knowledge. Клиент показывает состояние задачи и изменения, человек принимает решение по предложению. Отмена задачи останавливает выполняемую попытку, но не откатывает ранее принятое изменение.

## Работа по принятому изменению

Подписки указаны явно в конфигурации доменов. Tasks обрабатывает принятое изменение и назначает Runtime работу домена проверки комплаенса при изменении продукта или комплаенса. Повтор доставки одного события не создаёт новую независимую задачу.

При изменении каталога ограничений пересматривается применимость к продуктам в выбранной базе, включая ограничения без существующих сопоставлений. Результаты проверки сами не запускают эту же проверку: домен не подписан на себя. Runtime выполняет только назначенную ему попытку и не владеет подписками или повторами задач.

## Граница реализации

[Граница компонента](module.md) определяет место исполнения. Подключение LLM, очередь событий и работающий agent harness здесь не реализованы.
