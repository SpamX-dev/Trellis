# Trellis Runtime

Runtime исполняет назначенные задачи внешними CLI/SDK-агентами. Жизненным циклом управляет [Tasks](../trellis-tasks/module.md); доступом к проектам и рабочим копиям — [Knowledge](../trellis-knowledge/module.md).

Для первого [product-сценария](../trellis-framework/plan.md) Runtime получит закреплённый пакет из [Registry](../trellis-registry/module.md), передаст агенту инструкции, навык, декларации моделей и примеры, а также разрешённую рабочую копию. Агент читает существующие YAML-документы, записывает изменения и создаёт локальный commit. Его отчёт содержит статус и резюме; документы остаются в Git.

Runtime передаёт отчёт Tasks. Точный commit и его содержимое для гейтов предоставляет вызывающий компонент через Knowledge. Runtime не решает, прошла ли задача гейты, и не принимает изменения за человека. При отмене Tasks останавливает попытку исполнения.

[Граница компонента](module.md) определяет место исполнения. Запуск LLM, очередь событий и работающий agent harness пока не реализованы.
