# Граница Trellis Runtime

## Назначение

Runtime исполняет агентов доменов по [контрактам Framework](../trellis-framework/module.md). Он собирает инструкции и навыки, предоставляет схемы и инструменты, фиксирует входы и передаёт предложения на проверку.

## Ответственность

- Выбор домена и агента по конфигурации.
- Фиксация снимков Framework и документов для запуска.
- Получение разрешённых снимков и инструментов от Knowledge; предоставление файлового чтения, поиска и при необходимости MCP в ограниченной среде запуска.
- Запуск авторских и смысловых проверяющих навыков.
- Обработка явно объявленных подписок на принятые изменения.
- Управление повтором и отменой работы с сохранением её идентичности.

## Границы

Knowledge применяет изменения; Runtime готовит и передаёт предложения. [Identity](../trellis-knowledge/identity/module.md) подтверждает личность, [Projects](../trellis-knowledge/projects/module.md) проверяет проектные права, а [Repositories](../trellis-knowledge/repositories/module.md) предоставляет разрешённые снимки и рабочие копии. Runtime может дополнительно ограничить инструменты и доступ к файлам, но не расширить разрешения Knowledge. Поле домена само по себе не предоставляет прав.

Управление проектами и доставка внешних [webhook](../trellis-knowledge/webhooks/module.md) принадлежат Knowledge и не требуют запуска агентов в Runtime. Уведомление об изменении ветки предложения не заменяет событие принятия документов и не создаёт подписку автоматически.

Граф ссылок не задаёт расписание запуска агентов. События обрабатываются по подпискам, включая случай нового документа, у которого ещё нет связей с другими доменами. Новые версии инструкций не изменяют уже начатый запуск.
