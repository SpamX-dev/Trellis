# Автоматизация поставки

## Ответственность

Этот блок объединяет автоматизацию сборки Grafel, сборки расширения, проверки совместимости и упаковки единого VSIX для Windows x64.

## Границы и зависимости

Автоматизация вызывает средства сборки компонентов, используя исходники `grafel/` и `plugin/`. Собственные процедуры сборки движка остаются в его репозитории. Анализ кода, управление рабочими процессами пользователя и интерфейс редактора принадлежат соответствующим компонентам, а не сборочным скриптам.

## Ограничения

Сборка использует коммит Grafel, зафиксированный submodule. Получение обновлений upstream — отдельная операция сопровождения; сборка не меняет выбранную ревизию. Генерируемые файлы размещаются в игнорируемых каталогах артефактов и не подменяют исходники.
