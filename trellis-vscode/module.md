# Граница Trellis VS Code

## Назначение

Клиент предоставляет работу с доменными документами по контрактам [Framework](../trellis-framework/module.md): выбор агента, человекочитаемое представление, просмотр изменений, применение и отклонение предложения.

## Ответственность

Клиент отображает исходный YAML, рендер документа, различия, результаты проверок и неизвестные данные. Решение человека относится к конкретному содержимому предложения и базовой ревизии.

## Границы

Клиент использует известную продуктовую модель для представления документа и не вводит собственные доменные ограничения. Структурные проверки и применение выполняет Knowledge; запуск агента — Runtime.

Редактирование YAML создаёт рабочие изменения. Рендер является представлением для чтения; обратное преобразование произвольного отредактированного текста не подразумевается. Применение отображается завершённым только после подтверждения Knowledge.
