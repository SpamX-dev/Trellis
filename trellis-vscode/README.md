# Trellis VS Code

Пользовательский интерфейс для работы с YAML-документами и доменными агентами.

Основные действия человека:

1. Выбрать домен и открыть документ либо вызвать агента для его заполнения.
2. Просмотреть исходный YAML и человекочитаемое представление.
3. Сравнить предлагаемое и принятое содержание; увидеть замечания и пробелы.
4. Применить предложение или отклонить его.

Представление продуктовых документов будет строиться из известных типов [Framework](../trellis-framework/module.md). Исходный YAML и diff должны оставаться доступны, чтобы интерфейс не скрывал содержательные изменения.

Проверка структуры, AI-замечания и решение человека отображаются отдельно. Конфликт базовой ревизии требует обновления предложения и повторного просмотра.

[Граница](module.md) определяет зависимости от Knowledge и Runtime. Исполняемое расширение, команды редактора и интеграция MCP здесь не реализованы.
