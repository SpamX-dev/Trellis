# Граница Trellis Registry

## Назначение

Registry распространяет неизменяемые версии пакетов агентов и навыков по контрактам [Framework](../trellis-framework/module.md).

## Ответственность

Каталог хранит имя, точную версию, контрольную сумму, содержимое, сведения о способе исполнения и происхождение пакета. Пакет описывает одну ограниченную задачу и содержит инструкции `AGENTS.md`, выбранные YAML-навыки, детерминированные гейты и схемы входа и выхода со всеми разрешёнными зависимостями. Registry проверяет формат и целостность, позволяет выбрать последнюю опубликованную версию и предоставляет точный пакет для загрузки Runtime. Изменение содержимого требует новой версии.

## Границы

Авторские определения агента находятся рядом с доменными контрактами [Framework](../trellis-framework/module.md); опубликованный пакет является результатом сборки и доставки через CI/CD. В нём сохранён один согласованный набор схем: [Tasks](../trellis-tasks/module.md) использует его для гейтов, а [Runtime](../trellis-runtime/module.md) передаёт текст схем агенту. Tasks выбирает пакет при создании задачи и сохраняет точную версию и контрольную сумму его содержимого. Новая публикация не меняет уже созданную задачу. Локальная работа с авторскими определениями не требует каталога пакетов.

Пакет описывает поведение агента, а его учётная запись и проектные полномочия принадлежат [Knowledge](../trellis-knowledge/module.md). Registry не хранит документы продукта, не принимает изменения знаний, не запускает агентов и не выдаёт разрешения на инструменты. Публикация пакета не означает его подключения или содержательной корректности результатов.
