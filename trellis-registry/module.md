# Граница Trellis Registry

## Назначение

Registry распространяет неизменяемые версии пакетов агентов и навыков по контрактам [Framework](../trellis-framework/module.md).

## Ответственность

Каталог хранит имя, точную версию, содержимое, сведения о способе исполнения и происхождение пакета. Он проверяет формат и целостность, позволяет выбрать последнюю опубликованную версию и предоставляет выбранный пакет для загрузки Runtime. Изменение содержимого требует новой версии.

## Границы

Авторские определения агента находятся рядом с доменными контрактами; опубликованный пакет является результатом сборки для исполнения. [Tasks](../trellis-tasks/module.md) выбирает пакет при создании задачи и сохраняет точную версию и контрольную сумму его содержимого. Новая публикация не меняет уже созданную задачу. Локальная работа с авторскими определениями не требует каталога пакетов.

Пакет описывает поведение агента, а его учётная запись и проектные полномочия принадлежат [Knowledge](../trellis-knowledge/module.md). Registry не хранит документы продукта, не принимает изменения знаний, не запускает агентов и не выдаёт разрешения на инструменты. Публикация пакета не означает его подключения или содержательной корректности результатов.
