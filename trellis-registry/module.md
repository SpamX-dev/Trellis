# Граница Trellis Registry

## Назначение

Registry распространяет неизменяемые версии пакетов агентов и навыков по контрактам [Framework](../trellis-framework/module.md).

## Ответственность

Каталог хранит идентификатор, точную версию, содержимое и происхождение пакета. Он проверяет формат и целостность и предоставляет версии для загрузки Runtime. Изменение содержимого требует новой версии.

## Границы

Авторские определения агента находятся рядом с доменными контрактами; опубликованный пакет является результатом сборки для исполнения. Локальная работа с этими определениями не требует каталога пакетов.

Registry не хранит документы продукта, не принимает изменения знаний, не запускает агентов и не выдаёт разрешения на инструменты. Публикация пакета не означает его подключения или содержательной корректности результатов.
