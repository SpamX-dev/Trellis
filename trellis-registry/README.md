# Trellis Registry

Распространение версий агентов и навыков.

Исходные определения находятся в доменах [Framework](../trellis-framework/domains/module.md). При упаковке фиксируются исходная ревизия, схемы и состав навыков. Опубликованная версия однозначно определяет содержимое.

Runtime может использовать локальные определения из зафиксированного снимка Framework. Registry нужен для распространения и выбора опубликованных пакетов; он не является обязательным посредником чтения YAML-документов.

[Граница](module.md) отделяет распространение от исполнения и принятия знаний. Формат транспортного API и работающий сервер каталога здесь не реализованы.
