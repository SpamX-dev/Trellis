# Trellis Registry

Распространение версий агентов и навыков.

Исходные определения находятся в доменах [Framework](../trellis-framework/domains/module.md). При упаковке фиксируются исходная ревизия, схемы, состав навыков и сведения о способе исполнения. Опубликованная версия однозначно определяет содержимое.

В целевом цикле [Tasks](../trellis-tasks/module.md) выбирает опубликованный пакет при создании задачи и закрепляет его точную версию и контрольную сумму. Runtime получает этот пакет для исполнения. Локальная работа с авторскими определениями Framework не требует Registry; он не является посредником чтения YAML-документов проекта.

Пакет задаёт поведение агента, но не его учётную запись и не проектные права: ими владеет [Knowledge](../trellis-knowledge/module.md).

[Граница](module.md) отделяет распространение от исполнения и принятия знаний. Формат транспортного API и работающий сервер каталога здесь не реализованы.
