# Trellis Registry

Распространение версий агентов.

## Целевой пакет

Один пакет соответствует одной ограниченной задаче. Исходное определение product-агента находится в [Runtime](../trellis-runtime/agents/product/agent.md), а сборка комплекта принадлежит [Framework](../trellis-framework/module.md). Будущий пакет содержит текст агента, декларации моделей и примеры.

CI/CD доставляет самодостаточный пакет из выбранной ревизии Framework в Registry. Tasks использует соответствующую версию библиотечных проверок для гейтов, а Runtime передаёт файловый комплект агенту. Пакет хранит исходную ревизию, точную версию и контрольную сумму; изменение содержимого требует новой версии.

В целевом цикле [Tasks](../trellis-tasks/module.md) выбирает опубликованный пакет при создании задачи и закрепляет его точную версию и контрольную сумму. [Runtime](../trellis-runtime/module.md) получает этот пакет для исполнения. Локальная работа с авторскими определениями агентов не требует Registry; он не является посредником чтения YAML-документов проекта.

Пакет задаёт поведение агента, но не его учётную запись и не проектные права: ими владеет [Knowledge](../trellis-knowledge/module.md).

[Граница](module.md) отделяет распространение от исполнения и принятия знаний. Сборка комплекта product-агента, доставка через CI/CD, формат транспортного API и работающий сервер каталога ещё не реализованы.
